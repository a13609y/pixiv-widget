# Pixiv 每日美图 · Egern 小组件

Egern 小组件：按小组件尺寸自动挑画幅的 Pixiv 壁纸轮播，可选登录态跟随热门搜索。

- **两种搜索源**：第三方代理（服务端支持横/方/竖、时段筛选）/ 官方网页（直连 pixiv，免登录可用）
- **三个脚本**：抓 Cookie（`http_request`）、每小时检测登录态（`schedule`）、小组件本体（`generic`）
- **请求极少**：冷却期内 0 请求；一次搜索管 36 张；全看过会随机重复并暂停搜索 6 小时

## 安装

```
https://raw.githubusercontent.com/a13609y/pixiv-widget/main/setu.yaml
```

1. Egern → 工具 → 模块 → `+` → 粘贴上面的地址 → 保存
2. 点进模块，在「环境变量」区域按需调整（共 23 项，见下表）
3. 桌面长按 → `+` → Egern → 选尺寸 → 长按小组件 → 编辑 → 选「每日美图」

> 模块对远程脚本有 **24 小时缓存**（`update_interval` 默认 86400）。项目更新后必须「删掉模块重新导入」，否则跑的还是旧代码。

### 想要登录态（可选）

只有拿到登录 Cookie 才能用「热门搜索」，其余功能免登录即可。

1. 模块自带 `mitm.hostnames`，不用手动加
2. Egern → 设置 → 证书：安装描述文件，再到 iOS「设置 → 通用 → 关于本机 → 证书信任设置」里打开
3. 确认 Egern 正在接管流量
4. Safari 打开 `pixiv.net`（已登录状态）随便点两下
5. 收到 **🔑 已抓到 Pixiv Cookie** 通知即成功

## 工作流程

```
读配置 → 冷却期内？(按尺寸独立缓存) → 直接渲染，0 请求
      → 池里挑（先过滤防重复窗口，再按画幅档位）
      → 池空 / 全看过 → 搜索一页（36 条入库）
      → 下载图（主备图床 + 降档）→ 落盘 → 渲染
```

- **候选池**：一次搜索的 36 条存本地，配合冷却把请求压到每天 1~2 次
- **防重复**：最近 N 张（默认 30）不重复；全都在窗口内时随机重复一张，并记时间，**6 小时内不再为找新图反复搜索**
- **画幅档位**：中号/超大号 `横图 → 方图 → 兜底`，小号/大号 `方图 → 近方 → 兜底`；代理模式下若指定了画幅，本地不再挑，避免白翻页
- **失败兜底**：代理失败 → 自动回退官方网页；搜索失败 → 用缓存图并延长刷新

## Cookie 与登录态

| 场景 | 行为 |
| --- | --- |
| 抓到新 Cookie | 🔑 已抓到 Pixiv Cookie（每小时最多一条） |
| 游客 → 登录 | 🔑 必提示 |
| 值没变但 6 小时没提示 | ✅ 抓取正常（Cookie 未变）报平安 |
| 每小时检测发现掉线 | 🔒 登录态失效（每 6 小时最多一次，点击直达 pixiv.net） |
| 网络异常 | 不判定失效，不提示 |

判断登录态用的是 `/ajax/user/self` 的 `userData` 是否为 null——比热搜接口可靠（后者会被 Cloudflare 干扰）。

**整串 Cookie 会被保存并回放**（含 `cf_clearance`）。只带 `PHPSESSID` 会被 Cloudflare 判成机器人，这是「明明登录了却当成游客」的根源。

## 调试角标

`DEBUG` 打开后，图左下角显示一行：

```
🔑 1.78/2.1 · in · ♻重复 · trending · 拦截23:05
```

| 位置 | 含义 |
| --- | --- |
| 🔑 / 🔒 | 登录 Cookie 生效 / 未生效 |
| `1.78/2.1` | 作品画幅 / 目标画幅 |
| `in` | 档位：`in` 横图、`near` 方图、`skip` 服务端已筛、`relaxed` 兜底 |
| `♻重复` | 这张在防重复窗口内，属于重复 |
| `trending` | 词来源：热搜 / `config` 你填的 / `default` 兜底 / `-` 直接用了候选池 |
| `拦截HH:MM` | 抓包脚本最后一次被调用的时间（不依赖通知也能确认抓包链路） |

## 排障

| 现象 | 先查 |
| --- | --- |
| 一条通知都没有 | 模块是否重新导入；`匹配正则` 是否生效 |
| 有「✅ MITM 生效但无 Cookie 头」 | 该请求确实没带 Cookie（隐私窗口/未登录） |
| 抓到 Cookie 但拿不到热搜 | Cookie 是游客态，或 `cf_clearance` 过期，重新登录 |
| 改了开关没变化 | WidgetKit 刷新预算；删掉小组件重新加最快 |
| 图片很糊 | 可能是 `/custom-thumb/` 路径没归一（脚本已处理） |
| 中号出竖图 | 池里横图耗尽：调大翻页上限，或改用代理 + 画幅=横图 |

## 已知限制

- 第三方代理是他人服务，可能限流或下线；已做自动回退
- 「只要R18」在官方网页模式下需要登录 Cookie，免登录会拿不到结果
- 官方网页搜索的 `type` 参数无效，插画/漫画只能本地过滤
- 图床只白名单 360/540 两档缩略，720 以上返回 403
- `schedule` 脚本只在 Egern 运行期间触发，App 被杀时错过的会在下次启动补跑
- 刷新时机由 WidgetKit 决定，`refreshAfter` 只是建议值
